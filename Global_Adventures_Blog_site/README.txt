GLOBAL ADVENTURES BLOG — навчальний сайт

Файли:
- index.html — головна сторінка
- cities.html — описи трьох міст
- gallery.html — фотогалерея
- contact.html — контактна форма
- subscribe.html — форма підписки
- css/style.css — оформлення
- favicon.svg — значок сайту

Перегляд локально:
Відкрийте index.html у браузері.

Публікація через GitHub Pages:
1. Створіть репозиторій на GitHub.
2. Завантажте в нього всі файли й папку css (не завантажуйте лише ZIP).
3. У репозиторії відкрийте Settings → Pages.
4. У розділі Build and deployment виберіть Deploy from a branch.
5. Виберіть гілку main і папку /(root), натисніть Save.
6. Дочекайтеся публікації. GitHub покаже адресу сайту в Settings → Pages.

Примітка: контактна форма та підписка є демонстраційними й не зберігають/надсилають дані на сервер.
Зображення завантажуються з Unsplash, тому для їх відображення потрібен інтернет.
